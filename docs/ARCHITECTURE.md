# Структура проекта

- `index.html` — главная страница библиотеки игр
- `assets/site.css` — стили главной страницы
- `games/smart-coins/index.html` — разметка игры «Остров умных монет»
- `games/smart-coins/styles.css` — внешний вид игры
- `games/smart-coins/data.js` — задания викторины
- `games/smart-coins/city.js` — город и мастерская
- `games/smart-coins/missions.js` — сюжетные миссии
- `games/smart-coins/app.js` — состояние, монеты, накопления, сохранение, звук и интерфейс
- `scripts/check.mjs` — автоматическая проверка файлов, связей и синтаксиса JavaScript
- `.github/workflows/check.yml` — запуск проверок при изменениях

## Как развивать дальше

Каждую новую игру помещать в `games/<slug>/`; у каждой собственные HTML/CSS/JS и постоянная ссылка. Общие компоненты появятся в `shared/`, когда их действительно начнут использовать несколько игр.

Сохранение игры использует прежний ключ `kids-smart-coins-v1`: **не переименовывать без миграции**.

### Правила безопасности изменений
1. Не помещать игровые данные и код в HTML.
2. Запускать `node scripts/check.mjs` до публикации.
3. Не менять пути открытых ссылок без редиректа.
4. Новые поля состояния добавлять с безопасными значениями по умолчанию.
5. После изменения механик проверять игру в браузере (особенно управление на телефоне, звук и сохранения).

Сайт статический, без сервера и внешней базы данных. Прогресс хранится только на устройстве ребёнка.

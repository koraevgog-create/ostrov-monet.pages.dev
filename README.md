# 🌟 Остров открытий

Небольшая расширяемая детская образовательная игровая площадка (начальный возраст: 5–8 лет).

## Сейчас работает
- Главная страница с каталогом игр: `/index.html`
- Первая самостоятельная игра «Остров умных монет»: `/games/smart-coins/index.html`
- Игра учит различать потребности и желания, понимать ценность труда, беречь деньги, копить на цель, сравнивать цены и помогать другим.
- 12 вопросов; игровые монеты, звёзды, магазин, копилка и добрые дела.
- Локальное сохранение через `localStorage`; без авторизации, сторонней аналитики и платежей.

## Как добавлять новые игры

Каждая игра живёт в собственной папке `games/<slug>/index.html`. Добавляйте новую папку и карточку в корневом `index.html`. Такой подход позволяет внедрять независимые игры и постепенно вынести общие элементы в `shared/` без необходимости переделывать существующие URL.

## Публикация

Репозиторий поддерживает простой статический хостинг. Для GitHub Pages откройте **Settings → Pages → Build and deployment → Deploy from a branch**, затем выберите **main**, папку **/(root)** и нажмите **Save**. После публикации путь будет:
`https://koraevgog-create.github.io/ostrov-monet.pages.dev/`.

Также репозиторий можно подключить к **Cloudflare Pages** как статический сайт: build command пустой, output directory `/` (корень репозитория). Название репозитория само по себе не создаёт домен `ostrov-monet.pages.dev` — его потребуется отдельно назначить при создании проекта Cloudflare.

## Принципы проекта
- Польза и возрастная понятность важнее сложных механик.
- Крупные кнопки, доступность на мобильных устройствах, интерфейс на русском.
- Без денежных платежей и рекламы. Сохранение только в браузере пользователя.
- Новые игры добавляются отдельно, действующие ссылки не изменяются.
